# Country snapshot

`countries.snapshot.json` is generated by `npm run data:refresh` and committed so
catalog, profiles, sitemap, builds, and deploys never consume a country-data API
quota.

Source: [mledoze/countries](https://github.com/mledoze/countries), commit
`9eff32e4eef26715aa59d99b200127d1ef150e7a`, licensed under
[ODbL 1.0](https://github.com/mledoze/countries/blob/9eff32e4eef26715aa59d99b200127d1ef150e7a/LICENSE).

The generator projects source fields into Atlasia's internal `CountryDetail`
contract. Runtime code validates every generated record with Zod before exposing
it to queries. Update the pinned commit deliberately, run the quality gates, and
review the generated diff before committing a refresh.
